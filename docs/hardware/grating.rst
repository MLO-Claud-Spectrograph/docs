Grating: Newport 270R, master 1294
==================================

The dispersive element is a Newport ``270R`` plane ruled reflection grating
replicated from master 1294. The 270R ruling has 300 grooves/mm and a nominal
first-order Littrow blaze wavelength of 500 nm (4.3° nominal blaze angle). The
installed grating is used away from Littrow in the instrument's fixed-deviation
geometry, so the in-instrument efficiency peak is not expected to coincide with
500 nm exactly.
