Fiber: Thorlabs FG105LVA
========================

The fiber feed uses Thorlabs ``FG105LVA`` multimode step-index fiber. Its
105 µm core is both the physical entrance aperture in the telescope focal plane
as well as the size (in object space) of the exit pupil inside the instrument,
and thus directly impacts the imaged trace width and spectral resolution.

.. list-table:: Key catalog properties
   :header-rows: 1
   :widths: 40 60

   * - Property
     - Value
   * - Core diameter
     - 105 µm
   * - Numerical aperture
     - 0.10
   * - Fiber type
     - Multimode, step index
